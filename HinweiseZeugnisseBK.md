# Zeugnisformulare Berufskollegs nach APO-BK

## Allgemeine Hinweise

### Lernfelder
Für die Lernfelder muss in SchILD unter *Fachklassen* im Feld *Lernfelder* eine rtf-Datei eingefügt (oder der Inhalt getippt) werden. Diese erscheint genau so auf der Anlage bzw. (bei A3-Zeugnissen) auf der 
Zeugnisrückseite auf Seite 4. 
Gleichzeitig wird (wenn es einen Lernfeldeintrag dort gibt) eine entsprechende Fußnote mit Verweis auf die Anlage gesetzt.
